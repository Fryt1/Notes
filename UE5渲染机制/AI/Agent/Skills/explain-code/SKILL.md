# 代码解释 Skill

用直观的方式解释代码如何工作。

## 解释方法

### 1. 从类比开始
将代码概念与日常生活中的事物对比：
- 函数 → 工厂流水线
- 类 → 蓝图/模板
- 循环 → 重复做某件事
- 异步 → 点外卖等待

### 2. 绘制图表
使用 ASCII 艺术展示：

**数据流程**：
```
输入 → [处理] → 输出
  ↓
[验证]
```

**类关系**：
```
    Parent
      ↑
      |
    Child
```

**调用链**：
```
main()
  ├─ init()
  ├─ process()
  │   ├─ validate()
  │   └─ transform()
  └─ cleanup()
```

### 3. 逐步讲解
按执行顺序解释：
1. 首先发生什么
2. 然后做什么
3. 最后输出什么

### 4. 突出陷阱
指出常见错误：
- ⚠️ 容易混淆的地方
- 🐛 常见 bug
- 💡 最佳实践

## 解释模板

```
## 📖 这段代码做什么

[一句话总结]

## 🌰 类比

就像 [日常生活的例子]...

## 📊 工作流程

[ASCII 图表]

## 🔍 详细步骤

1. **步骤1**：[解释]
2. **步骤2**：[解释]
3. **步骤3**：[解释]

## ⚠️ 注意事项

- [陷阱1]
- [陷阱2]

## 💡 关键概念

- **概念1**：[解释]
- **概念2**：[解释]
```

## 适用场景

- 学习新的代码库
- 理解复杂算法
- 代码审查时的说明
- 团队知识分享
- 教学和培训
