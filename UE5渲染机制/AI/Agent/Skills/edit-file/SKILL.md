# 文件编辑 Skill

帮助用户高效地修改文件内容。

## 使用场景

- 修改配置文件
- 更新代码文件
- 批量替换内容
- 重构代码

## 编辑策略

### 1. 小范围修改（推荐使用 Edit 工具）
当需要修改文件的特定部分时：
- 先用 Read 工具读取文件
- 找到需要修改的确切内容
- 使用 Edit 工具进行精确替换

**优点**：
- 保留文件其他部分不变
- 精确控制修改范围
- 避免格式问题

**示例**：
```
1. Read 读取文件
2. Edit 替换 old_string -> new_string
```

### 2. 大范围修改（使用 Write 工具）
当需要重写整个文件或大部分内容时：
- 先用 Read 工具读取原文件
- 修改内容
- 使用 Write 工具覆盖整个文件

**注意**：Write 会覆盖整个文件，确保保留需要的内容

### 3. 批量修改（使用 Grep + Edit）
当需要在多个文件中修改相同内容时：
- 用 Grep 查找所有包含目标内容的文件
- 对每个文件使用 Edit 工具替换

## 修改前检查清单

✅ **必须做**：
1. 先用 Read 读取文件，确认当前内容
2. 确认要修改的确切字符串（包括空格、缩进）
3. 如果是代码文件，保持原有的缩进格式
4. 修改后告知用户具体改了什么

⚠️ **注意事项**：
- Edit 工具的 old_string 必须完全匹配（包括空格）
- 如果有多处相同内容，考虑是否需要 replace_all: true
- 修改配置文件前，建议先备份
- 对于重要文件，先询问用户确认

## 常见修改任务

### 修改配置值
```
任务：将 port: 3000 改为 port: 8080
步骤：
1. Read config.json
2. Edit: "port: 3000" -> "port: 8080"
```

### 重命名函数
```
任务：将函数名 oldFunc 改为 newFunc
步骤：
1. Grep 查找所有使用 oldFunc 的文件
2. 对每个文件 Edit 替换
```

### 更新导入路径
```
任务：更新 import 路径
步骤：
1. Grep 查找旧路径
2. 批量 Edit 替换为新路径
```

### 添加新内容
```
任务：在文件末尾添加内容
步骤：
1. Read 读取文件
2. Write 写入原内容 + 新内容
```

## 错误处理

如果 Edit 失败：
1. 检查 old_string 是否完全匹配（包括空格、换行）
2. 重新 Read 文件，复制确切的内容
3. 如果内容太复杂，考虑用 Write 重写整个文件

## 输出格式

修改完成后，清晰告知用户：
- ✅ 修改了哪个文件
- 📝 具体改了什么（旧值 -> 新值）
- 📍 如果是多个文件，列出所有修改的文件
