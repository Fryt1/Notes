## 一、这个项目到底是什么

`RealityDistortion` 不是一个单独材质，也不是一个普通后处理。

它本质上是一套接进 **UE5 渲染管线** 的“空间裂隙 / 力场挖洞”系统，想做成的不是“看起来像有洞”，而是：

1. **receiver 几何真的被裁掉**
2. **主视图能看到裂隙视觉**
3. **阴影 / VSM 也承认这个洞**
4. **场景里还能看到力场球壳的显示层**

所以这套东西一直同时包含 4 条并行链路：

- 主视图几何裁切
- ShadowDepth / VSM 阴影正确性
- `HoleInfoTexture + Composite` 的最终裂隙视觉
- `field visualizer` 的球壳显示层

## 二、当前阶段到哪了

以 **2026-03-16** 这次补记为准，当前状态可以压成一句话：

**correctness 主链已经基本打通，当前最大的残留缺口已经不是“有没有洞”，而是“洞开了以后里面长什么样”。**

也就是：

### 2026-03-16 补记：这轮修掉的不是视觉 bug，而是运行时崩溃

之前打开关卡时，VS 很容易停在 `StructuredLog.cpp`。

但那并不是根因，只是 UE 统一处理 fatal 的停靠点。真实报错是 `D3D12DescriptorCache.cpp` 里的：

- `Missing uniform buffer at slot 1, stage SF_Pixel`

而且问题发生在 masked material 的 `DepthPassParallel / PrePass`。

最后的稳定解，不是继续盯 `StructuredLog`，也不是只改 `D3D12Commands`，而是回到 `DepthRendering.h/.cpp`：

- 给 `FDepthOnlyPS` 绑定持久的 `RealityDistortionDepthPass`
- 用 `UniformBuffer_MultiFrame` 保住一份稳定的 `FRHIUniformBuffer*`
- 每帧在 prepass 前更新这份 uniform buffer

现在 `SampleMap` 已经能正常 `MAP LOAD`，并走到 `Map check complete`。

### 已经基本成立的部分

- receiver 主视图挖洞
- 阴影 / VSM 对洞的承认
- masked `DepthOnly` 预深度路径的 uniform buffer 运行时稳定性
- `SceneColorInputTexture` 驱动的裂隙合成
- 力场可视化球壳的组件链路

### 还没有彻底闭环的部分

- `interior / cap pass`
- 真实切面 / 内壁
- 某些角度下的空壳感和穿帮
- 半透明阴影这类相邻但不同的复杂话题

## 三、为什么不能把它理解成“一个半透明材质”

这个问题其实是这套项目最关键的认知分水岭。

### 问题：既然切口材质最后会用到 `SceneColorInputTexture`，那是不是直接画个不透明或半透明面贴上去就行？

**回答：不是。**

`SceneColorInputTexture` 只解决一件事：

**洞里最终显示什么背景。**

它不解决另一件更根本的事：

**前面的 opaque receiver 有没有真的从可见性、深度、阴影里被拿掉。**

如果不先挖洞，就算你最后在那个位置做了漂亮的 composite：

- 前面的 receiver 仍然已经写进 `SceneDepth`
- 前面的 receiver 仍然已经参与了主视图着色
- 前面的 receiver 仍然可能继续参与挡光

所以最终得到的，只会是“在原物体结果上又叠了一层东西”，而不是“这个物体真的在这里被切开了”。

这也是这套项目为什么一定要同时改：

- `DepthOnly`
- `BasePass`
- `ShadowDepth`
- `VSM`
- `Composite`

## 六、你现在应该记住的 3 句话

### 1. 这不是“一个材质球”，而是一套跨主视图、阴影、VSM 和 composite 的渲染系统。

### 2. `SceneColorInputTexture` 不能替代挖洞，它只能回答“洞里显示什么”，不能回答“前面的不透明 receiver 是否真的不存在”。

### 3. 现在最大的下一个阶段目标不是“再多加一点花纹”，而是把 `interior / cap pass` 做出来，让洞内部真正成立。

## 结论

到 **2026-03-16** 为止，这套 `RealityDistortion` 项目已经从“一个想法”长成了一套 **主视图、深度、阴影、VSM、显示层共同承认的空间裂隙系统**。这轮还额外补稳了 `DepthOnly` masked prepass 的 uniform buffer 运行时问题。当前最值得继续推进的方向，仍然是在 correctness 基本成立的前提下，把内部切面和内壁真正补完整。
